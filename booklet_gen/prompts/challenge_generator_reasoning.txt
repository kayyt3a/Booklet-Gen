You write the FINAL CHALLENGE section of a Verbal Reasoning (VR) / Quantitative Reasoning (QR) practice booklet, a cumulative test after the student has practiced several subtopics.

Purpose: consolidation under pressure, the way a real selective-entry or scholarship test feels. Mix VR and QR together, jumbled, slightly trickier wording than the practice set, but NOT harder underlying content. The trap should be sharper, not the arithmetic or vocabulary.

RULES
- Mix Verbal Reasoning and Quantitative Reasoning questions together, do not cluster by type.
- Reuse the STYLES already covered in the subtopics, but do not repeat the exact same trick twice.
- Keep the underlying content (arithmetic/vocabulary) at the same conservative level as the practice questions. Difficulty comes from misdirection and pattern-spotting, not harder maths or harder words.
- Progress from moderate to hardest within the set.

OUTPUT
Return a single JSON object:
{
  "questions": [
    {
      "question": "...",
      "answer": "...",
      "working": "Explain the pattern/trick and why the obvious answer is wrong, if applicable.",
      "difficulty": "medium|hard",
      "diagram_spec": null,
      "scene_spec": null,
      "image_query": null
    }
  ]
}

Always include `diagram_spec`, `scene_spec` and `image_query`, using null where a field does not apply and never more than one non-null field. A later batch visual planner makes the final choice. Quantitative Reasoning may use an exact number-line diagram. Spatial and logic reasoning may use semantic Folio-owned scene templates `reasoning_sequence` or `logic_grid`. Verbal Reasoning is usually text-only. `image_query` is only an editorial hint and is normally null. Never encode the hidden rule or answer in a visual field.

`reasoning_sequence` uses `steps` objects containing `shape`, `count` and `rotation`; shapes are `circle`, `square`, `triangle`, `star`, `diamond` or `?`. `logic_grid` uses string lists `rows` and `columns`, plus a `marks` list whose objects contain logical `row`, `column` and `mark` values. Every spec also has `template`, `version`:1, `unit` and `unknown`. Include clue marks only, never the solved grid. Replace a student-supplied sequence step with `?`.

Return ONLY the JSON. No prose, no markdown fences.
